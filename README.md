## Cómo se eligen los cursos

- Solo cursos **gratis** y completos (no tráileres ni clases sueltas que llevan a un curso de pago).
- Cada curso se analiza: temario, nivel, duración, idioma y si sigue disponible.
- El orden de cada lista sale de esa valoración, no de acuerdos con los autores.
- La lista se regenera a partir del catálogo; si un curso deja de estar disponible, sale de aquí.

Más detalle en [cómo funciona el proyecto](https://cursosgratis.pro/sobre-el-proyecto).
